# Plan feature

Renders the current response plan as an operations plan, not as an AI answer.

Must show, per assignment: boat, team, site, action, priority, and the three
explanations the backend supplies (evidence summary, remaining uncertainty,
compatibility rationale).

Must show, per deferred site: the fallback action and the binding constraint
stated plainly, for example "intervention deferred because of capacity
constraints".

Must show the re-planning latency when a plan was produced by a recompute.
