# .agents

Working material for the humans and AI assistants on this project.

| Path | What it holds |
| --- | --- |
| `rules/commit-rules.md` | Branch names, commit messages, PR expectations. |
| `rules/code-rules.md` | How code in this repository is expected to be written. |
| `rules/multi-agent-rules.md` | How three people and their assistants work in parallel without colliding. |
| `teammates/frontend.md` | What the frontend track owns and does not own. |
| `teammates/data.md` | What the data and ingestion track owns and does not own. |
| `teammates/agents.md` | What the agents and backend-logic track owns and does not own. |

Project context is in `CLAUDE.md` at the repository root.
General rules are in `AGENTS.md` at the repository root.

Everything here is prose, not configuration.
Nothing in this directory is read by a build step, so it can be edited freely as the project learns things.
